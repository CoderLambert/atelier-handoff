# 前端

- React 组件使用 TypeScript props 和语义化交互元素。页面负责组合已有 feature，组件通过 props 或领域 hook 表达行为。优先复用 shadcn/ui 的 `components/ui`、主题变量和既有的键盘与焦点约定，按组件 UI 规则完成 PC 中大屏验收。
- 通过 `use-query/<领域>/` 的具名 hook 访问运行时，通过已声明的 preload 契约请求原生能力。桌面组件与普通 Web 组件分别处理各自可用的能力。文件系统、凭据和进程归宿主。
- 列出加载、空结果、成功、错误和重试的界面行为，特别关注异步操作时仍保留草稿和选择。异步回调要绑定发起请求的项目或会话。
- 弹层验证初始焦点、Esc、焦点恢复和原生视图遮挡。长文本、代码与表格在自己的容器滚动。尺寸、滚动或输入改动用真实中、大尺寸桌面窗口操作验证。
- 以交互行为测试重要路径。共享组件提取应至少有明确的消费者和稳定输入。
