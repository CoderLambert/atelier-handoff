# atelier. AI 工作台 · 设计与开发交接

这是面向 Claude Agent SDK 的个人 AI 工作台项目。当前包含**可编辑的静态交互原型、完整开发说明、任务清单与独立 T01 SDK 验证程序**。T01 已完成本机 Shunt / gpt-6.1-sol 路线的真实能力验证；产品页面仍未接入 SDK、后端、数据库或实际项目操作。

## 从这里开始

1. 打开 [index.html](index.html) 查看当前第二轮优化版设计。
2. 阅读 [完整产品与开发交接说明](docs/development-guide.html)，了解功能、交互、数据与接入边界。
3. 使用 [开发任务清单](docs/development-tasks.md) 拆分实施工作、记录进度和验收证据。
4. 对照 [原始参考图](image.png) 理解视觉来源。它不是当前优化版截图。
5. 阅读 [T01 SDK 验证报告](docs/t01-sdk-validation.md) 与 [独立实验运行说明](experiments/t01-agent-sdk/README.md)：Node 24.21.0、SDK 0.3.326、Shunt 0.64.0，14 项离线测试与 7 项真实场景已通过。真实实验消耗模型额度，和不收费的前端演示分开。

## 如何打开

将整个目录或 ZIP 解压后的内容放在一起，用支持现代 JavaScript 的桌面浏览器打开 `index.html`。`styles.css` 和 `app.js` 必须与它保持同级。文档入口是 `docs/development-guide.html`，不依赖外部 CDN、远程字体或构建步骤。

根目录原型仍没有 `package.json`、开发服务器或生产构建脚本，查看页面无需安装依赖，也不存在根目录 `npm run dev` / 后端启动命令。`experiments/t01-agent-sdk/` 另有独立 npm 工程和验证命令，详见其 README；它不会启动产品页面或后端。浏览器或宿主预览限制本地脚本、存储、下载时，以相应环境限制为准。

HTML 文档带有打印样式，可通过浏览器打印功能使用；本次没有生成或验证 PDF。Markdown 文件可用任意文本编辑器或代码托管平台打开。

## 当前可体验的原型流程

- 初始示例为“登录页体验优化”，处于等待审批状态。
- 可新建、搜索和切换会话，查看会话、执行轨迹和交付物。
- 在回复中先查看关键发现，再展开执行摘要和工具详情。
- 在右侧或弹窗查看示例差异，允许或拒绝后改变模拟状态。
- 允许后约 1.8 秒完成模拟，展示可预览和下载的示例 Markdown。
- 新会话发送包含“模拟失败”的文字，可体验失败提示与重试。
- 工具栏更多选项可打开权限说明与设置；设置中可重置演示数据。
- Enter 发送，Shift + Enter 换行；Ctrl / Cmd + K 新建会话。

这些都是前端演示，不会调用提供商、不产生模型费用，也不会读写真实项目。文件选择只保存展示用文件名，不上传文件内容。示例中的项目、身份、运行时间、代码差异、用量与费用不可作为实际业务数据。

## 保存行为与已知限制

会话尝试保存到浏览器 `localStorage`，键为 `atelier-workbench-v1`；存储不可用时仅在内存运行。草稿和折叠状态目前只在内存保存，刷新后不保留。加载缓存时 `running` 会被改为 `stopped`，这是原型处理方式，不是真实任务恢复。

如果打开后看到的是此前操作的状态，可通过设置中的“重置演示数据”恢复初始示例；此操作会清除原型内新增会话。当前源码没有独立的 Run 模型，执行列表主要按会话展示；新任务可能复用登录表单分析、审批差异和成果模板。详细缺口见主文档第 13 节。

## 设计基线

- 浅色背景、鼠尾草绿强调色、细分隔线、三栏工作区。
- 正文 16px，常用 UI 13–14px，辅助信息 12px。
- 对话优先呈现结论；工具过程默认收拢。
- 审批明确说明操作范围与原因；项目配置、权限和用量按需展开。
- 所有设计变量集中在 `styles.css` 的 `:root`；当前文件是视觉事实来源。

## 开发阅读顺序

1. 主文档第 4 节：完整功能范围 F01—F16。
2. 第 5—7 节：核心流程、状态与审批约束。
3. 第 8—11 节：模块边界、数据模型、建议接口与事件流。
4. 第 12—13 节：源码映射及真实实现缺口。
5. 第 14—16 节与任务清单：验收、依赖顺序、待验证 SDK 能力。

建议先做两条纵向链路：“真实读取项目并给出建议”与“经审批修改一个真实文件”。不要直接把 `schedule()` 的定时模拟或 `diff()` 的固定模板接入生产。

## 移交与维护

`atelier-handoff.zip` 采用白名单打包，根目录为 `atelier-handoff/`，含上述 7 个源文件与文档；ZIP 本身不递归包含。宿主内部元数据、隐藏运行目录、缓存、依赖与凭据不属于交接包。现有产品源码及参考图保持原位置，避免同时维护两份设计源码。

ZIP 是本次快照。后续改动先更新对应源码或文档，再重新生成压缩包。产品需求以 HTML 主文档为准；任务状态与证据在 Markdown 任务清单中维护；启动说明与文件入口在本 README 中维护。

原始参考图的作者与许可未随素材提供，本项目仅保留用户提供素材用于设计对照，不宣称额外授权。
