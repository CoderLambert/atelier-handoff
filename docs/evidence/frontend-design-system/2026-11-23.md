# 2026-11-23 前端设计系统验收

## 条件

使用当前工作区的生产前端和开发桌面构建。Linux x64、Node 26.13.1、Electron 45.4.1，前端测试指定系统 Chromium。Electron 使用临时项目、数据根、独立 profile 和回环模型响应，实际模型请求费用为零。基线与新版使用相同构建命令。验收尺寸是 renderer 的 CSS 视口。

## 结果

| 验收入口 | 结果 |
| --- | --- |
| `npm run check` | 架构、查询边界、i18n、UI 规范及所有 TypeScript 检查通过。UI 检查覆盖硬编码颜色、旧控件类、名称缺失和全量 Motion 入口。 |
| `ATELIER_TEST_CHROMIUM=/usr/bin/chromium npm test` | 运行时 289 项通过，前端 109 项通过，0 项失败。原生 WebFetch 长回执缺少确定性本地夹具，既有 1 项跳过。 |
| `npm run build`、`npm run build:desktop` | 两项通过。 |
| `node --import tsx scripts/sidebar-smoke.mts` | 1440×900 验证项目树、搜索、会话菜单、归档/恢复、删除取消、焦点和长标题。 |
| `node --import tsx scripts/smoke-i18n.mts node_modules/electron/dist/electron dist/desktop/main.mjs` | 真实 Electron 中英文切换、profile 重开持久化、运行时恢复通过。 |
| `node --import tsx scripts/smoke-context-usage.mts` | 1280×800 中文、1440×900 英文、1920×1080 配置页面和 680px 导航抽屉通过。原生网页实际接受输入，键盘与拖拽调整分栏后槽位与网页宽度差 ≤2 CSS px。弹层打开时原生网页分离，关闭后恢复。草稿在切换标签和重开后保留，窄窗关闭后焦点归还，系统减少动效时按钮为零过渡时长。 |
| `node --import tsx scripts/smoke-tool-activity.mts` | 真实 Electron 和 SDK 使用回环模型。会话与轨迹间切换、浏览器返回、4,585 字符命令、217,623 字节日志的分页、下载校验和焦点恢复通过。 |

首次验证会话标签键盘导航时，懒加载轨迹面板暂时隐藏整个会话区域，键盘焦点丢失。将 Suspense 边界移入标签面板后，同一入口验证方向键、Home、焦点和草稿恢复均通过。

`frontend/src/features/inspector/tool-detail.test.ts` 使用 Chromium 计算六种工具状态的前景和背景，文字对比度均 ≥4.5:1。主题配对计算得到正文 14.19:1、导航辅助文字 5.37:1、主按钮 6.76:1、状态淡底最低 5.84:1、输入边界 3.57:1、导航焦点 5.62:1。
