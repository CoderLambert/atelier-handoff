# 运行时 HTTP 拆分验收（Linux x64）

基线：`2218b97` 加本轮开始时已存在的工作区改动。对照的入口是恢复时的 2,650 行版本，其中已有的插话可用性检查随同迁入，没有覆盖。新入口 299 行，最长的 HTTP 源文件 126 行。依据与回退见 [运行时组合与 HTTP 领域路由](../../decisions/2026-11-26-runtime-http-modules.md)。

## 验证结果

| 验证 | 结果 |
| --- | --- |
| `npm run check` | 架构、Query、i18n、UI 和四组 TypeScript 检查通过。新增边界测试覆盖限额和禁止 HTTP/领域模块反向导入组合入口。 |
| `npm test`（指定内置 RTK 和系统 Chromium） | 运行时 800 通过、2 跳过；前端 140 通过。覆盖真实 HTTP / SQLite / Git / PTY，以及锁定 SDK 和本地回环的会话用例。未调用付费模型。 |
| RTK 补充用例 | 打开 `ATELIER_TEST_REAL_RTK=1` 后单独补跑全量中的一个 RTK 跳过项，通过；另一个 WebFetch 跳过项仍没有可复现的本地模型夹具。 |
| `npm run build`、`npm run build:desktop` | 生产 renderer、Electron main 和 preload 构建通过。 |
| `scripts/smoke-git-live-sync.mts` | 在隔离 Wayland/Electron 窗口用真实 Git、锁定 SDK 和回环模型验证：暂存与差异在 Bash 运行中刷新，提交在对话结束前出现在历史列表，旧提交详情不被替换，两次外部改写都刷新同一文件的差异，切换到英文后重开面板仍自动更新。正常关闭了测试窗口。 |

关停测试让原生目录选择的替身保持待定，并保持真实 HTTP SSE 流打开；关闭运行时取消选择、结束流并移除监听，重复关闭重用同一个 Promise。另一个测试在临时 SQLite 中证明运行回执与会话事件在同一事务回滚，清理一个会话不影响另一个。没有新增数据库迁移、运行依赖或 Electron IPC。

全量首跑的新增关停测试有一处 Promise 构造误用，修正后定向和全量均通过；同一首跑中未改动的 Skill broker fixture 报 `BrokenPipeError`，单项复跑与随后完整复跑通过。未改 broker。最初 Electron 缺少当前有效显示参数，显式使用 Wayland 后上屏；旧脚本打开模态框后再输入，聊天框处于 `inert`，改为先发送再打开，用夹具分别释放暂存和提交，未修改产品 UI。

完整本机日志和截图：`.local/runtime-http-modules-20261127/`（`check-final.log`、`test-final.log`、`test-initial.log`、`broker-repro.log`、`rtk-optional.log`、`build.log`、`build-desktop.log`、`electron-git-final.log`、`git-smoke-final.png`）。这是源码开发态验收；没有构建或安装新的发行包，也没有切换日用实例。

## 复现

```sh
npm run check
ATELIER_TEST_RTK_BINARY="$PWD/dist/linux/atelier/resources/rtk/rtk" \
  ATELIER_TEST_CHROMIUM=/usr/bin/chromium npm test
ATELIER_TEST_REAL_RTK=1 node --import tsx --test \
  --test-name-pattern='real pinned RTK preserves XDG' tests/builtin-rtk-packaging.test.ts
npm run build
npm run build:desktop
node --import tsx scripts/smoke-git-live-sync.mts
```

RTK 用例需要本机已有通过哈希核对的固定发行二进制与归档。桌面脚本需要可用的 X11/Wayland；无默认显示时，可在临时目录为脚本入口准备一个 `opt/atelier/atelier` 启动器，转发到本仓 `node_modules/electron/dist/electron dist/desktop/main.mjs --ozone-platform=wayland`，传临时目录路径作为脚本参数。脚本自行创建独立 HOME、数据目录、profile、Git 仓库和模型网关。该启动器不代表安装件。
