# 桌面包内置 Shunt

Linux x64 安装件附带经校验的 Shunt 0.64.0。Electron 主进程和工作台运行时沿用既有生命周期边界。主进程启动 Shunt 并通过回环监听地址确认就绪，将地址交给工作台运行时。退出先停工作台运行时，再关闭独立的网关进程。已有外部网关可通过设置或显式启动参数接入。

[Shunt 0.64.0 启动实现](https://github.com/pleaseai/shunt/blob/ace707b/src/main.rs#L724) 支持系统分配的回环端口，并在绑定后输出监听地址。配置保存在工作台数据目录的 `shunt/shunt.toml`，按初次创建方式写入，升级和重启沿用同一个文件。数据库保存网关来源和外部地址，内置 Shunt 的运行端口由当前主进程提供。

[Shunt ChatGPT Plan 登录](https://shunt.sh/zh-cn/guides/chatgpt-plan/) 使用系统浏览器授权并在 Shunt 自己的持久账号目录管理凭据。沿用系统现有的 Shunt 账号目录和其跨进程刷新锁，工作台仅展示是否存在账号记录。设置中的登录操作调用同一随包 Shunt；浏览器回调成功后配置文件和账号目录在后续启动继续使用。

验证实际归档内的二进制、无登录目录的启动、回环服务可达、同目录重开后的配置和账户位置、正常退出及用户此前的会话数据。使用既有授权判断是否需要登录，并保留外部网关作为回退选项。
