# 会话级运行模式

输入区的运行模式随当前会话保存，后续发送继续使用所选模式。新会话继续默认只读。会话草稿已有 SQLite 持久化与串行保存，因此在原草稿 DTO 增加可选审批模式。既有 `mode` 表达可用工具范围，运行创建时仍记录本次生效的审批方式。受限智能体和只读续接继续由服务端校验。

[Codex App Server](https://learn.chatgpt.com/docs/app-server) 将审批策略设在 thread 层，并在创建 turn 时确定实际运行范围。Atelier 用会话草稿保存当前选择，沿用请求字段和版本约束冻结每次实际执行。原有字段保留，旧记录缺失新字段时按逐次审批。旧版应用回退后，以受控修改方式打开新草稿。

已知计费的「全网搜索」Skill 继续由用户为本轮填写单次上限，确认发送后归零。模式切换不授予项目或智能体新工具。原生下拉改成 [shadcn Select](https://ui.shadcn.com/docs/components/select)，费用选项收进按需打开的小对话框。验收覆盖连续两轮、会话隔离、重开、停止和只读续接的模式边界。
