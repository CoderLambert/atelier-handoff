# Git 阅读器代码引用

读取文件时可以将选区作为当前会话的草稿引用。沿用会话引用卡片、数量和发送长度限制，以及 [会话选区引用方案](2026-11-22-composer-quotes-and-insert.md)。选区以代码 DOM 的实际文本偏移计算原文件行号。工具栏和既有 `Alt+Shift+Q` 快捷键复用同一操作。复制路径使用阅读器显示的仓库相对路径。

引用作为显式用户动作进入同项目当前会话的草稿，保留片段快照及文件版本来源。选中的内容只在用户发送会话时进入模型请求。草稿允许旧引用形状，不改写已有草稿或表结构。项目、工作树和会话边界在现有工作区状态层核对。

在隔离 Electron 与本机 Git 中验证语法高亮后的跨行选区、行号、同一片段去重、草稿保留与路径复制。若回退入口，保留兼容的引用字段和发送格式，已有草稿仍带文件来源。
