# 会话输入区的提交与模型设置

输入区始终显示同一个发送箭头。运行中普通提交由现有运行时决定是否入队，输入区避免重复展示这一默认动作，队列区显示已入队项目。保留既有停止、Enter、Shift+Enter 与可用时的 Alt+Enter 行为，将键盘说明保留为辅助技术描述。

模型和推理深度通过一个组合入口调整。参考 [Radix Popover](https://www.radix-ui.com/primitives/docs/components/popover) 的非模态定位和焦点恢复，复用工作台 `Popover` 和既有模型、档位下拉控件。保留默认模型、固定档位、手填 ID、目录刷新和来源隔离的既有规则。

会话内的弹层用两行展示设置名称和当前值，点选相应行打开现有选项列表。固定档位显示当前值和悬停说明。Git 多提交继续使用共享选择器的独立控件。

验证同一个发送图标在空闲与运行中的提交、IME、队列与立即插入，以及在组合入口选择模型和深度、固定档位及手填流程。变更只涉及交互外观和焦点，可独立回退前端。
