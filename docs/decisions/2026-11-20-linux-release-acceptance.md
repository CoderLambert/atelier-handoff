# P7 Linux 发布验收

P7 复用 P1 冻结的发行包和 P2 探测的关闭预算。从同一安装件验证工作台窗口、运行时、原生网页、附件和交付物、迁入与回退。先执行在隔离数据上可以完成的本机验收，分发使用单独的签名和许可证审查。

用户可从桌面设置保存 JSON 诊断。报告采用显式字段，包含应用、Electron、系统、架构和当前运行时连通状态。按 [Electron app API](https://www.electronjs.org/docs/latest/api/app) 读取应用版本，按现有原生文件模块保存。版本和能力足以定位安装或系统兼容问题。诊断报告始终以字段清单生成，凭据、内容、数据目录、网页和项目路径不属于字段范围。

验收用真实桌面窗口选择隔离目录并检查 JSON。包体、启动耗时、峰值内存、安全设置、进程与许可证条目沿用 P1/P2 的证据口径。需要对外分发时，确认应用许可证和已验证过的第三方许可证文本，按发布者明确授权执行签名和分发。
