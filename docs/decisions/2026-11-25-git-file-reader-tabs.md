# Git 文件阅读标签

完整文件预览覆盖了正在核对的差异，单个窄弹窗也无法在两份文件之间切换。把文件打开行为接入 Git 工作区的现有标签行。固定入口保留文件变动、提交历史和工作树，打开的文件紧随其后，以文件名和版本区分。文件阅读使用独立滚动区、行号与现有语法高亮。宽侧栏和全窗口共用一套布局。

参考 [DSH 文件差异标签身份](https://github.com/cherrchen/dsh-plugin-git/blob/v0.2.14/src/client/tab-definitions.ts#L55-L72) 与 [ARIA 标签键盘约定](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)。按工作树、路径、内容来源和历史提交去重。关闭当前文件后选相邻文件或返回最近的基础视图。基础视图保持挂载，保留选中的变更或提交。只渲染当前文件，切换前保存横纵滚动位置。阅读标签归当前 Git 工作区，不写入会话数据库。

沿用现有项目 API 与 Electron 定位契约。用隔离 Electron 验证跨文件切换、同路径不同版本、键盘操作、返回差异与侧栏/全窗口切换。回退仅涉及 Git 前端的预览入口和阅读布局。
