# 在多个项目中手动选用同一个 MCP

当同一个本机 MCP 能根据工作目录切换仓库时，在每个项目重复粘贴进程命令会导致配置和授权漂移。新增明确的「所有项目可手动选用」选项，沿用 MCP TypeScript SDK 的 [`stdio` 传输](https://github.com/modelcontextprotocol/typescript-sdk) 和工作台的项目扩展授权，不启用 Claude SDK 的隐式配置加载。

设置仍由原项目管理，无需复制记录；仅普通聊天的选择目录扩展可见范围。共享仅支持本地 stdio，以通过连接测试且已授权的工具作为上限。共享关闭自动提供；跨项目调用需要受控修改并逐次由用户审批，即使会话为其他工具启用了自动审批。运行期间重新检查原版本、启用状态及共享状态。其他项目的智能体绑定和 Skill 工具绑定不继承共享配置。连接以扩展、实际调用项目和工作目录分开；OpenWiki 适配器仍自行确认 Git 工作树。

验证两个项目的管理/选择目录、显式选用、撤权、连接隔离和逐次审批。回退时在原项目关闭共享即可，不变更各仓库的 Wiki 数据。
