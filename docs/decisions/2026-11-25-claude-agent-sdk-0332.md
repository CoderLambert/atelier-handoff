# Claude Agent SDK 0.3.332 升级

Atelier 当前发行基线使用 SDK 0.3.326 和配套的 Claude Code 2.1.326。升级到 0.3.332 可采用 2.1.332 的 SDK MCP 重连修复和前台子代理输出文件标识。现有模式继续由 `query()` 的显式配置决定，项目工具沿用顶层 MCP 注册和现有审批回调。

[Anthropic 固定版本变更记录](https://github.com/anthropics/claude-agent-sdk-typescript/blob/v0.3.332/CHANGELOG.md)列出了 hook 数组和参数序列化校验、`setPermissionMode()` 返回值及子代理消息变化。现有 hook 采用数组，运行时在启动时指定权限模式。Linux 打包脚本从锁文件和 SDK 清单取得配套 CLI 版本，并在安装目录里校验 CLI 身份。

采用单独升级 SDK 及其平台 CLI 依赖。隔离副本使用 npm 实际解析并安装后，锁文件中只变化了 SDK 和八个配套平台包。只更新依赖时，12 个用例在 `0.3.326` 的版本断言处退出。同步更新三份测试夹具的断言后，真实 Linux SDK、回环模型下的审批、同批子代理、单独停止和会话续接全部通过。保留旧会话分叉夹具中的 2.1.326，用于验证旧记录可读。

验证包括类型检查、全量测试、前端和桌面构建、Linux 安装件的实际 CLI 和隔离运行。回退时恢复原依赖声明、锁文件及测试断言，正常退出后用原版本的 CLI 和桌面构建打开同一数据目录。该升级没有定义新的 SQLite 迁移。
