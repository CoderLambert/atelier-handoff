# 输入区引用与快捷插入

参考 [Codex 的 Queue 与 Steer](https://developers.openai.com/blog/mastering-codex-remote-for-engineering) 区分默认排队和主动插入。Atelier 选择输入区内的 `Alt + Enter` 提交当前草稿并尝试实时插入，复用现有排队回执、插入接口和运行时兼容性检查。普通 `Enter` 继续发送或排队。无法实时插入时保留已排队的消息，优先执行仍需通过现有队列按钮选择。

引用是草稿中的可移除卡片。记录引用消息标识和选中时的正文快照，避免消息流式更新、重开或切换会话改变已选内容。沿用草稿 JSON 和既有正文上限，发送时将引用与用户输入组合成原有的 Markdown 正文。已有草稿中的 Markdown 保留原样。

助手正文中的单条消息选区可通过「引用所选」或 `Alt+Shift+Q` 添加引用，按 Esc 收起按钮。片段使用独立卡片标识，并记录来源消息标识，同源且文本一致的片段去重。已有整条引用继续使用原有的格式，草稿读写兼容两种卡片。

验收输入区快捷键、输入法、会话切换、保存失败、发送重试和队列落点。使用回环替身和隔离 Electron 环境，无须调用实际模型。
