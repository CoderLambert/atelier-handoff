# atelier. 开发任务清单

配套主文档：[产品与开发交接说明](development-guide.html)。功能 ID（F01—F16）和验收 ID（A01—A14）以主文档为准。

本清单面向正式产品开发。所有实施任务初始均为待办；交接资料已整理不等于 SDK 或产品能力已完成。每项只有在实现存在、相应验收通过并记录证据后才能勾选。

**2026-11-18 更新：T01—T20 已按个人本机首版范围完成。** 用户要求功能优先、按功能本地提交；实现、验收层次和保留限制见 [本机首版完成记录](local-release.md)。截图工具未完成截图，不声称像素级视觉验收通过；多尺寸与键盘操作有真实浏览器记录。

## 使用约定

- 每个任务记录负责人、状态、提交 / PR、验证命令或可复现步骤、结果与遗留问题。
- 依赖未完成时可以做隔离的界面或契约准备，但不能宣称端到端完成。
- SDK 能力无法确认时记录证据与替代方案，不使用固定示例伪装真实能力。
- P0 必须闭环；P1 不阻塞最小真实任务，但也不能通过删除功能编号静默取消范围。
- 任何生产页面保留演示能力时必须显式区分来源，生产状态不能被演示缓存污染。

## 原任务补验记录

- **T07 / A05、A14**：重复请求停止只记录一次状态转换，随后关服保留首次停止原因。启动期间取消会在启动 SDK 进程前退出。以 `npm test` 的 `repeated stop and shutdown preserve the first cancellation and finalize once` 为证据。
- **T08 / A04、A14**：异步文件基线检查完成后重新校验当前审批状态和期限。以 `npm test` 的 `permission expiry during the file baseline check prevents approval` 为证据。
- **T11 / A06、A07**：收到高于数据库当前记录位置的 SSE 游标时，服务端发送 `cursor-reset`，客户端刷新快照并继续接收新事件。HTTP 集成测试验证了 `Last-Event-ID` 优先、游标重置和随后新事件送达。
- **T12 / A02、A12**：历史消息列出该轮已读取的项目文件和附件。已使用的附件从草稿移除后，历史保留其名称和引用，后续请求拒绝再次引用已移除项。HTTP 集成测试覆盖历史和越权引用，隔离浏览器测试覆盖移除附件请求等待期间切换会话及草稿归属。

本次补验使用本地集成测试和隔离浏览器数据。全套真实模型验收的结果与范围仍以首版完成记录为准。
