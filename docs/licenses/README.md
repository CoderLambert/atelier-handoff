These npm packages declare the MIT license and lack a standalone license file in their tarballs. The package inventory includes the following supplemental notices.

- `remark-math@6.0.0` from the upstream repository at `d5d0660b150810a535bbb07eac6cc96a4510aa24`. [Source](https://github.com/remarkjs/remark-math/blob/d5d0660b150810a535bbb07eac6cc96a4510aa24/license)
- `rehype-katex@7.0.1` from the upstream repository at `88a9497e1ede93b958237c85edbf5651faeca7af`. [Source](https://github.com/remarkjs/remark-math/blob/88a9497e1ede93b958237c85edbf5651faeca7af/license)
- `standardwebhooks@1.1.1` from the upstream libraries directory at `b4d2c14fc5b4ccff3ff271e3b087dff812254c59`. [Source](https://github.com/standard-webhooks/standard-webhooks/blob/b4d2c14fc5b4ccff3ff271e3b087dff812254c59/libraries/LICENSE)
- `fastdom@1.0.12` and `strictdom@1.0.1` from the License sections of the READMEs shipped in the locked npm tarballs. [FastDom tarball](https://registry.npmjs.org/fastdom/-/fastdom-1.0.12.tgz) · [StrictDOM tarball](https://registry.npmjs.org/strictdom/-/strictdom-1.0.1.tgz)
- `react-remove-scroll-bar@2.3.8` declares MIT in its npm manifest and README. The supplement is the standalone MIT notice that the upstream project added on 2025-05-21, after the npm version was published. [Published metadata](https://registry.npmjs.org/react-remove-scroll-bar/2.3.8) · [Upstream notice](https://github.com/theKashey/react-remove-scroll-bar/blob/7301c160fda44cb8cf2b9fdfde61efad35736196/LICENSE)

`rtk-oss-1.2.1-LICENSE.txt` is the unmodified Apache-2.0 `LICENSE` from the pinned [RTK OSS v1.2.1 Linux x64 musl archive](https://github.com/rtk-ai/rtk/releases/download/v1.2.1/rtk-oss-x86_64-unknown-linux-musl.tar.gz), including the RTK AI Labs copyright notice. Its SHA-256 is `33f694a31d9f9df3e292a9413a3cdb0113fa72698e2c719f657ff6b53165dcc4`. Linux packaging includes it at `resources/licenses/rtk/LICENSE`; the license, release and resource inventories record the bundled executable and fixed launcher. Version, asset URL and all three upstream hashes are maintained in `shared/builtin-rtk.ts`.

The packager accepts `ATELIER_BUILD_RTK_ARCHIVE` for an existing pinned archive. Otherwise it reuses `.local/cache/rtk/<archive-sha256>/rtk-oss-x86_64-unknown-linux-musl.tar.gz`, downloading the fixed asset into a fresh directory when absent. Every path validates the archive hash before extracting into a separate empty directory, then validates the binary and original license. The cache is optional; a clean checkout can reproduce the input from the fixed URL and hash. Packaging never runs RTK or installs its upstream hooks.
